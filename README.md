# Python Operators Practice

## 📝 Description
A comprehensive collection of Python scripts demonstrating the behavior and usage of different operator types. This repository was created as part of my foundational Python learning journey with **@Codanics**.

## 📂 Files and Topics Covered

| File Name | Operator Type | Description |
| :--- | :--- | :--- |
| `arthamtic.py` | Arithmetic | `+`, `-`, `*`, `/`, `//`, `%`, `**` |
| `assinment_operator.py` | Assignment | `=`, `+=`, `-=`, `*=`, `/=`, etc. |
| `comparison_oprator.py` | Comparison | `==`, `!=`, `>`, `<`, `>=`, `<=` |
| `logical.py` | Logical | `and`, `or`, `not` |
| `membership_oprator.py` | Membership | `in`, `not in` |
| `indentity_oprator.py` | Identity | `is`, `is not` |

## 🎯 Purpose
To build a strong, practical understanding of Python's core operators—essential knowledge for data manipulation and analysis with libraries like Pandas and NumPy.
